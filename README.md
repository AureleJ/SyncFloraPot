# SyncFloraPot

## Description

SyncFloraPot is a complete solution for monitoring and controlling a smart plant pot.

## Directory Structure

``` TXT
SyncFloraPot/
├── firmware #Firmware code for the smart plant pots.
├── client #Client-side android/ios application for monitoring and controlling the plant pots.
└── backend #Server for communication between the client and the plant pots.
```
